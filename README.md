# Crypto Wallet App

A real wallet dashboard built with React and ethers.js.

## Features
- MetaMask wallet connection
- ETH balance display
- Token balances for USDC, USDT, WETH
- Send ETH and token transfers
- Portfolio value estimation
- Recent activity feed
- Copy wallet address
- Responsive dashboard UI

## Run locally
```bash
npm install
npm run dev
```

## Notes
- This app uses the browser wallet via MetaMask.
- It is configured for Sepolia-style testnet behavior and token addresses.
- For production, you would replace token addresses and add proper RPC configuration.
